# PORTFÓLIO BRUTALISTA — FOTO / VÍDEO

Landing page em HTML/CSS/JS puro, usando as imagens fornecidas.

## Estrutura
- `index.html` — página
- `style.css` — brutalismo, responsividade e animações
- `script.js` — reveal on scroll, cursor, hover magnético e tilt
- `assets/` — imagens

## Antes de publicar
Troque no `index.html`:
- `seuemail@exemplo.com`
- `https://wa.me/`

Não há gradientes. As fotos começam em preto e branco e ganham cor no hover, funcionando como contraste com o layout.
